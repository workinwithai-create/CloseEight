# CloseEight

Eight-bar closer desk for bedroom producers and AI-music finishers. Live FluidR3 chairs so a looping section finally has an ending.

## Why
85% of songs that get started never get finished. The loop has no closer. Session players write eight live bars that build, resolve, and land on the tonic.

## Features
- Lookahead scheduler on the AudioContext clock
- Live changes to BPM, key, chords, recipe while playing
- Seamless loop WAV export (48 kHz, 24-bit) and MIDI
- Pinned FluidR3 samples from PreEight commit d58301e4a494555f411a2afbc448b724136eee76
- User settings persist in localStorage
